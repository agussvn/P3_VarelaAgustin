## 📌 Descripción

Portfolio personal responsive desarrollado con **HTML5 y CSS3**, utilizando **Flexbox** como sistema principal de maquetación.

El proyecto cumple los siguientes requisitos:

- Uso de etiquetas semánticas.
- Diseño responsive con `flex-wrap`.
- Variables CSS para colores.
- Efectos `hover`.
- Código CSS comentado.
- Enlaces funcionales a proyectos.

---

## 🛠 Tecnologías

- HTML5  
- CSS3 (Flexbox)
